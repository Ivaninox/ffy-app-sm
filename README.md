# App SM · Refonte FFY

Prototype et Design System de la refonte de l'application mobile Street Marketeur.

En ligne : https://ivaninox.github.io/ffy-app-sm/

- `app-sm-prototype.html` : prototype navigable. Chaque écran a sa propre URL (`https://ivaninox.github.io/ffy-app-sm/app-sm-prototype.html#/mission/pil`, `#/terrain/oree/en-cours`, etc.), utilisée dans les tâches Jira de l'épic FFY-1655.
- `app-sm-responsive.html` : rendu iOS et Android sur 6 tailles d'écran (344 à 440 pt de large). Accepte la même adresse d'écran que le prototype : `app-sm-responsive.html#/terrain/oree/en-cours`.
- `app-sm-design-system.html` : Design System mobile.

Mise à jour : remplacer les fichiers HTML par leur nouvelle version, les URL restent les mêmes.
